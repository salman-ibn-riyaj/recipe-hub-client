# 🍽️ RecipeHub

RecipeHub is a modern full-stack recipe sharing platform where food lovers can discover, create, and share delicious recipes with the community. The platform provides a clean, responsive, and user-friendly experience with secure authentication, recipe management, premium features, and an engaging cooking community.

# ✨ Features

- 🔐 Secure Authentication with Better Auth
- 👤 User Profile Management
- 🍳 Create, Update & Delete Recipes
- 📖 View Detailed Recipe Information
- ❤️ Like Favorite Recipes
- 🔍 Search Recipes
- 🏷️ Filter Recipes by Category & Cuisine
- ⭐ Featured Recipes
- 🔥 Most Liked Recipes
- 💳 Premium Membership with Stripe
- 📱 Fully Responsive Design
- 🎨 Modern UI built with Tailwind CSS
- ⚡ Fast Performance with Next.js App Router
